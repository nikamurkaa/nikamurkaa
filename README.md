Микросервисный сервис учёта личных финансов с Telegram-ботом, FastAPI, PostgreSQL, аналитикой, бюджетами, импортом выписок и Mini App.

**Django · DRF · PostgreSQL · React · Docker · Nginx**

### [Secure Auth Service](https://github.com/nikamurkaa/secure-auth-service)
Security lab по безопасной аутентификации: bcrypt, JWT, RBAC, rate limiting, single-session protection, password reset и audit logging.

**Node.js · Express · JWT · bcrypt · OpenAPI · GitHub Actions**

### [WebSec SQL Injection](https://github.com/nikamurkaa/websec-sql-injection)
Практический security lab с уязвимым и защищённым API: SQL Injection, parameterized queries, input validation и security logging.

**Node.js · Express · SQLite · OpenAPI · automated tests**

### [ISP Database Design](https://github.com/nikamurkaa/isp-database-design)
Case study по проектированию информационной системы интернет-провайдера: ERD, нормализация, PostgreSQL/MySQL, views, functions, procedures, RBAC и архитектурная документация.

**PostgreSQL · MySQL · SQL · Database Design · System Design**
